# Host HITL bridge (CW-20261001-0488)

Tachyon validates plugin `status=ask` responses and optionally enqueues them through Tangent's supported Streamable HTTP MCP caller API. Tangent owns interactions and participant decisions. The host uses released `go-hitl v0.1.0` typed retrieval and terminal outcomes, and MCP SDK v1.8.0.

`TACHYON_TANGENT_MCP_URL` defaults to unset: asks retain prompt/options/context, with `state:"unavailable"`, `unavailable:"not_configured"`, and `continuation:"unavailable"`; no network request occurs. Set it to an operator-approved Tangent `/mcp` URL to enable enqueue/get/await. `TACHYON_TANGENT_ITEM_BASE` is a separately approved HTTP(S) operator link origin. If unset no item link is exposed. Returned links must match that origin and the exact `/hitl/items/{item_id}` path; unrelated origins, credentials, queries, fragments, and unsafe schemes are rejected. Configuration is validated before loading children.

Successful asks retain status/prompt/options/context and add `operation_id`, `item_id`, `item_url` when safe, `state`, `expiry`, and `continuation:"unavailable"`. Failed enqueue retains the ask and explicit unavailable information, never approval. Plugin-supplied host handles are discarded. Asks require a nonblank prompt, approval or attention kind (approval by default), valid future expiry, and no simultaneous data/error. HTTP verb bodies are bounded at 1 MiB; correlation accepts at most 32 KiB canonical payload and 32 KiB serialized enqueue data. Oversized asks remain unavailable without enqueue.

Correlation exists only in host memory, capped at 256 entries and 10 minutes (shortened by ask expiry). No existing entry is evicted to admit a new one. Restart, dead plugin, TTL, capacity, or missing correlation fails closed. Binding contains random host epoch, opaque operation ID, exact captured process generation, verb, and SHA-256 of canonical JSON payload; JSON numbers are never converted to float for the payload digest. Each initial invocation creates a distinct operation, even with identical verb/payload. Plugin trace correlations are nested beneath host-owned fields. The enqueue key is scoped to host epoch, operation ID, and ask generation. A lost enqueue response permits one bounded retry of the identical frozen request/key; it never dispatches the plugin again. Repeating POST /api/verb is a new invocation, not an idempotent write retry.

`GET /api/hitl/operations/{operation_id}` is read-only and returns validated authoritative status. Optional `wait_ms` is 0..50000; zero uses get, positive uses await. Each tool call, including initialization/cleanup, has a host budget (10 seconds for enqueue/get, 55 seconds for await's maximum 50-second wait; enqueue retry shares a 20-second ceiling). Responses are capped at 256 KiB. Status uses no-store and rejects explicit foreign Origin/cross-site browser requests. Missing Origin remains available to local clients; this check adds no authentication to the existing local-tool API.

The host validates request snapshot, item ID, revisions, contract version, lifecycle state, and typed terminal identity, then checks correlation again after waiting. `approved:true` means terminal `resolved` with response `{kind:"approval",decision:"approved"}` for an approval item. Attention, denial, canceled, expired, failed, superseded, malformed/forged status, and lookup failure never approve. Missing correlation returns HTTP410; backend/validation failure returns502 with approved false. Await timeout does not cancel Tangent's item.

**Continuation is unavailable.** There is no POST/resume route, no automatic verb replay after approval, and no provider call from status. Unknown write completion remains unknown. The current plugin carrier cannot safely express a trusted continuation; CW-20261001-0532 holds that design decision. Frontend pending treatment is a separate half of0488, gated on design-kit0039. This host change is not a complete HITL continuation runtime.
